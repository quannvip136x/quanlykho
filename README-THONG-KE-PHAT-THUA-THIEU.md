THONG KE NGUYEN VAT LIEU PHAT THUA / THIEU

Da bo sung vao ung dung:
- Menu "Thong ke phat thua/thieu".
- Tong hop theo ma nguyen vat lieu, tach cot "Ho no minh" va "Minh no ho".
- So du duong = ho no minh; so du am = minh no ho.
- Bam vao ma nguyen vat lieu de mo lich su phat theo ma, hien thi ngay gio, so luong phat thuc te, so luong tren phieu, phat sinh va so du sau phieu.
- Lich su duoc doc tu bang Supabase inventory_history; khong tao them bang va khong can chay SQL moi.

Cach chay local:
1. Sao luu thu muc app hien tai.
2. Giai nen ZIP nay vao thu muc moi.
3. Copy file .env tu app cu vao thu muc goc (khong chia se file .env).
4. Mo terminal tai thu muc app, chay npm install, sau do npm run dev.
